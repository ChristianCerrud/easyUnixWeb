> **A modern, responsive, and multilingual cheat sheet for essential Unix commands.**

EasyUnixWeb is a web application designed to help students and developers quickly find and understand standard Unix/Linux terminal commands. It features a real-time search engine and supports three languages (English, Spanish, and French), making it an accessible tool for international learners.

## ✨ Key Features

- **🔍 Real-Time Search:** Filter commands instantly by name or description as you type.
- **🌍 Internationalization (i18n):** Seamlessly switch between **English**, **Español**, and **Français**.
- **📱 Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- **🎨 Modern UI:** Clean interface built with CSS variables for easy theming.
- **⚡ Lightweight:** Built with Vanilla JavaScript (No heavy frameworks/dependencies).

---

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Flexbox, Grid, and Custom Properties (Variables).
- **JavaScript (ES6+):** DOM manipulation and logic for search/translation.

## 📂 Project Structure

```text

├── index.html      # Structure and content markup
├── style.css       # Visual styling and layout
├── script.js       # Logic (Search & Translation)
```
