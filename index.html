Présentation

Linux® est un système d'exploitation Open Source. Un système d'exploitation est un logiciel qui gère directement les composants physiques du système ainsi que ses ressources, telles que le processeur, la mémoire et le stockage. Il représente l'interface entre les applications et le matériel. C'est lui qui établit les connexions entre tous les logiciels et les ressources physiques requises pour l'exécution des différentes tâches.



LISTE DES COMMANDES


1) dnf
Utilité générale :

Utilisé pour installer des applications et mettre à jour le système.

Options/exemples
a) install dnf

Est utilisé pour effectuer la mise à jour des commandes dnf.

b) update dnf

Est utilisée pour effectuer la mise à jour dnf.

c) list

Cette commande indique si le paquetage spécifié est disponible dans tous les paquetages de dnf. Il s'agit d'une recherche rigide, ce qui signifie qu'elle répond au nom exact spécifié.

d) list | less

Est utilisé pour observer tous les paquets disponibles mais page pour page.

e)info

Fournit les détails du paquetage indiqué ci-dessous.

f) search

Pour rechercher un paquet dans les dépôts, tapez.

g) provides

Permet de savoir quels sont les fichiers utilisés ou contenus dans un paquetage.

h) grouplist

Cette commande permet de consulter une liste de paquetages regroupés.

i) groupinstall

Cette commande effectue l'installation d'un groupe choisi dans la liste disponible.

j) groupupdate <nom de groupe paquetage>

Est utilisé pour effectuer une mise à jour d'un groupe de paquets.

k) remove

Est utilisée pour désinstaller le paquetage sélectionné.

l) groupremove

Cette commande est utilisée pour désinstaller un groupe de paquets installés.

m) --exclude

Il est utilisé pour effectuer une mise à jour en faisant une exception du paquet indiqué dans la syntaxe.

n) check-update

Est utilisé pour vérifier si des mises à jour sont disponibles dans dnf.

o) update -y

Est d'effectuer toutes les demandes disponibles.

p) clean all

Supprime les fichiers de cache générés à partir des métadonnées du référentiel. Cela oblige DNF à régénérer les fichiers de cache lors de sa prochaine exécution.

Options/exemples

Permet d'effacer des fichiers, ne nécessite pas de confirmation de l'effacement et n'affiche pas de message de diagnostic.

b) -i

Est destiné à la suppression et demande à l'utilisateur de confirmer la suppression de chaque fichier. Si la réponse ne commence pas par "y" ou "Y", le fichier est ignoré. Si les options -f et -i sont données simultanément, la dernière option de la ligne de commande a l'avantage.

c) -r ou -R

Supprime de manière récursive les sous-répertoires. Cette commande nécessite une confirmation pour chaque fichier ou sous-répertoire à supprimer (ce qui peut prendre du temps).

20) ls
Utilité générale :

Il est utilisé pour lister les répertoires et les fichiers présents dans le dossier dans lequel nous nous trouvons.

Options/exemples
a) -F

Est de savoir si un fichier donné est normal, un répertoire, un lien symbolique, un exécutable ou un fichier réseau, mais n'a pas besoin d'informations sur les autorisations ou les propriétaires.

b) -R

Demande à ls d'énumérer les sous-répertoires de manière récursive.

c) -a

Linux utilise le point . comme préfixe pour les fichiers cachés. Ceux-ci sont parfois appelés fichiers point. Incluez-les dans la sortie à l'aide de l'indicateur -a.

d) -l

Énumère les détails des fichiers et des répertoires, y compris les autorisations, les propriétaires, les groupes, la taille des fichiers et les dates de modification, en énumérant un fichier ou un répertoire par ligne.

e) -r

Trier les fichiers en sens inverse.

f) -t

Trie le contenu des répertoires par date plutôt que par ordre alphabétique. Les fichiers les plus récents apparaissent en premier.

g) -u

Utilise la date du dernier accès aux fichiers au lieu de la date de modification.

h) -h

Ajoutez une lettre indiquant l'unité de taille, par exemple M pour mégaoctets, K pour kilooctets.

i) -m

Permet de lister le contenu des répertoires les uns après les autres en les séparant par une virgule.

j) -S

Trie les répertoires par taille de fichier plutôt que par ordre alphabétique. Les fichiers les plus volumineux sont affichés en premier.

k) -al

Afficher le contenu des sous répertoires

35) last
Utilité générale :

Cette commande permet d'afficher une liste des utilisateurs qui se sont connectés au système.

Options/exemples
a) -R

Permet d'afficher la date au format journal (secondes depuis le 1er janvier 1970).

b) -n num

Utilisé pour afficher un nombre limité d'enregistrements. Par exemple, "last -n 10" affichera les 10 dernières sessions de connexion.

c) -f fichier

Permet de spécifier le fichier journal à utiliser. Par défaut, "last" utilise "/var/log/wtmp" comme fichier journal, mais cette option vous permet de spécifier un autre fichier journal.

d) -adx

Est la combinaison de trois options qui permettent d'afficher toutes les sessions, y compris les inactives, et d'afficher l'adresse IP du terminal de connexion au lieu du nom d'hôte.

e) -a

Cette option permet d'afficher toutes les sessions de connexion, y compris les sessions inactives.

f) -d

Cette option permet d'afficher l'adresse IP ou le nom d'hôte du terminal à partir duquel vous êtes connecté.

g) -x

Cette option permet d'afficher des informations supplémentaires, notamment les utilisateurs actuellement connectés au système, ainsi que l'heure d'arrêt ou de redémarrage du système.

57) netstat
Utilité générale :

Cette commande permet d'examiner et de surveiller l'état du système et du gestionnaire de services.

Options/exemples

a) -tlnp

Cette option permet d'afficher les connexions TCP, les connexions en écoute (listening), les adresses de port et les numéros de port au format numérique, ainsi que les noms de programme et les ID de processus (PID) associés à chaque connexion.

b) -tlp

Cette option permet d'afficher les connexions TCP, les connexions en écoute (listening), ainsi que les noms de programme et les ID de processus (PID) associés à chaque connexion. (contrairement à la précédente, elle n'indique pas les numéros de port au format numérique)

c) -tnp

Cette option permet d'afficher les connexions TCP, les adresses et les numéros de port au format numérique, ainsi que le nom du programme et l'ID du processus (PID) associés à chaque connexion.

d) -lnp

Cette option permet d’afficher les connexions à l'écoute (listening), les adresses et les numéros de port au format numérique, ainsi que le nom du programme et l'ID du processus (PID) associés à chaque connexion.
